osx-window-manager · Window Manager for macOS

Changelog GitHub ↗

A menu-bar window manager for macOS: global keyboard shortcuts tile the frontmost window — halves, thirds, quadrants, displays. Small, fast, no Dock icon, no bloat.

Roughly a third of what it can do. Every tile lands pixel-exact; slides clamp at screen edges.

2026-08-31 Launch-at-login CLI; packaged dist/osx-window-manager.app is in the repo. Full changelog ↓

Details

Quarters that tile

Quarter tiles are half width × half height — four windows cover the screen edge to edge. Re-press slides the window to the next quadrant; movement stops at the screen edge instead of wrapping.

Plays nice with stubborn apps

Apps that enforce a minimum window size can't always shrink to a tile. Tiling animates to the ideal tile and then corrects — Electron apps (Slack, WhatsApp, …) ignore direct resize writes but accept animated ones. If the app still clamps, the HUD names it and its minimum size, and the window is re-pinned to the correct corner instead of hanging off-screen.

Rebindable

Click a key cap in Settings, press the new combo. Tiling gap 0–40 px, Launch at Login, one-click reset. Stored in UserDefaults domain osx-window-manager.

Native & tiny

Swift + AppKit + the Accessibility API — the same approach as Rectangle and Magnet. No Electron, no background daemons, one small binary. Requires macOS 14+.

Install

Clone and open the signed menu-bar app already in the tree (Apple Silicon, macOS 14+):

git clone https://github.com/lotar/osx-window-manager
cd osx-window-manager
open dist/osx-window-manager.app

Grant Accessibility when prompted: System Settings → Privacy & Security → Accessibility.

Start at login from Settings → Launch at Login, or:

dist/osx-window-manager.app/Contents/MacOS/osx-window-manager --enable-launch-at-login

Rebuild from source:

swift build
./.build/debug/osx-window-manager

./scripts/package.sh
open dist/osx-window-manager.app
